# Automatic-Trashcan
This is a project built with Arduino and C++
## Components
- Arduino Uno
- 400 tie-points breadboard
- SG90 Servo
- 4 AA batteries
- Ultrasonic sensor
- Cardboard
- M to M jumper wires
- M to F jumper wires
## How it works
- If an object is detected within 5CM, the servo rotates the lid open.
- If no object is detected within 5CM, the servo returns to closed position.
## Software
This project is programmed with Arduino IDE
